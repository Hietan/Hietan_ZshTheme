# Security Policy

## Supported versions

Security fixes are provided for the latest major release.

| Version | Supported |
| --- | --- |
| 2.x | Yes |
| 1.x and earlier | No |

## Reporting a vulnerability

Do not report suspected vulnerabilities in a public issue.

Use GitHub's private vulnerability reporting for this repository. Include the
affected version, environment, reproduction steps, impact, and any known
workaround. If private reporting is unavailable, contact the maintainer through
a private method listed on the maintainer's GitHub profile.

The maintainer aims to acknowledge a report within seven days and provide an
initial assessment within 30 days.
