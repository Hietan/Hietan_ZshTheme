# Support

Use [GitHub Issues](https://github.com/Hietan/Hietan_ZshTheme/issues) for
reproducible bugs and focused feature requests.

For display problems, include:

- The Hietan Zsh Theme version or Git commit.
- Zsh and Oh My Zsh versions.
- Terminal application and version.
- Nerd Font family and version.
- Relevant environment variables, such as `TERM_PROGRAM` and `CODEX_SHELL`.
- A screenshot and minimal reproduction steps.

For security vulnerabilities, follow [`SECURITY.md`](SECURITY.md) instead of
opening a public issue.
